# Letter Dataset Folder

This folder contains the ASL letter dataset in YOLO format.

Use this structure:

```text
letter_dataset/
├── train/
│   ├── images/
│   └── labels/
├── valid/
│   ├── images/
│   └── labels/
└── test/
    ├── images/
    └── labels/
```

Example matching image and label:

```text
letter_dataset/train/images/A_001.jpg
letter_dataset/train/labels/A_001.txt
```
